<objective>
Establish the repository substrate every other Phase 1 plan builds inside: an npm-workspaces monorepo,
the NestJS 10 Platform Core application skeleton whose module boundaries mirror
`TechArch/01-components.md` §4.1, the FRD Y2 error envelope, and — critically — the two **global**
guards registered deny-by-default so that no route created in any later plan can ever be
accidentally left open.

Purpose: `FRD/F00` states identity "is the gatekeeper for every other feature in the system; no
other feature may bypass it," and CONTEXT locks "One global NestJS guard is the authoritative
enforcement point … a route that forgets the decorator is silently open, which is precisely the
failure mode F00 forbids." The only way to guarantee that is to register the guard globally *before*
any protected route exists, and to have it deny by default from the very first commit. This plan
also fixes the single composition root (`app.module.ts`) so that eleven subsequent plans can each
work inside their own module directory without ever contending for the same file.

Output: A buildable, bootable, test-covered API skeleton with deny-by-default authorization, a CI
pipeline, and the `[ASSUMPTION]` register that CONTEXT requires be kept visible rather than silently
resolved.
</objective>

Create two route-metadata decorators. These are the **only** two ways a route can be exempted from
the full guard chain, and both exemptions are narrow and justified:

- `@Public()` (`IS_PUBLIC_KEY = 'isPublic'`) — no session required at all. Legitimate only for the
  authentication flow itself and `/health`, per `FRD/Y1a-api-shared.md`: "All require a valid session
  token (F00) except where noted as part of the authentication flow itself."
- `@SelfScoped()` (`IS_SELF_SCOPED_KEY = 'isSelfScoped'`) — session required, but **no resource ABAC
  evaluation**, because the endpoint's only subject is the caller's own identity and there is no
  target resource whose court/division/case/designation attributes could be evaluated. Legitimate
  only for `GET /auth/entitlements`, `POST /auth/logout`, `PATCH /users/me/workspace-preference`.
  Document this constraint in a comment on the decorator.

**This is not a bypass and must not become one.** CONTEXT explicitly rejected a dev-login path and
an MFA bypass flag. `@SelfScoped()` still requires a valid, MFA-satisfied session; it only skips the
*resource-attribute* half of the decision, for endpoints that have no resource.

`SessionAuthGuard` (registered **first**): if the handler or its controller carries `IS_PUBLIC_KEY`,
allow. Otherwise, in this plan's stub form, throw
`new ApiException(401, 'AUTH_SESSION_EXPIRED', 'Session expired; please sign in again')` — the exact
code and message from `FRD/F00` Error States. Plan 01-06 replaces the body with real session
validation; the registration and the public-route logic written here are permanent.

`AbacGuard` (registered **second**): if `IS_PUBLIC_KEY` or `IS_SELF_SCOPED_KEY` is present, allow.
Otherwise, in this plan's stub form, throw
`new ApiException(503, 'SECURITY_POLICY_UNAVAILABLE', 'Access cannot be evaluated at this time; request denied')`
— the exact code and message from `FRD/F13` Error States, which is also what
`FRD/Y2-errors.md` principle 1 ("Fail closed, not open") and CONTEXT's "If OPA is unreachable or
