|----------|-------------|
| contract→client | A published schema crossing into generated client code that shapes what requests the browser can construct. |
| developer→contract | Decorator-authored schemas crossing into the committed artifact other teams and phases rely on. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-60 | Elevation of privilege | A generated client offering `approving_user_id` on the publish call, teaching integrators that naming an approver is supported and eroding the separation-of-duties guarantee by convention | mitigate | `openapi/openapi.json#/components/schemas/PublishRulePackageRequest` omits the property and sets `additionalProperties: false`, with a description pointing at DEV-01; `openapi-contract.e2e-spec.ts` assertion 4 enforces both as schema assertions, and plan 02-08's handler rejects the raw-body key regardless. |
| T-02-61 | Tampering | Contract drift — the committed document silently falling behind the application, so the generated client sends shapes the server rejects or omits fields the UI needs | mitigate | `openapi-contract.e2e-spec.ts` deep-compares the emitted document with the committed one and enumerates the Nest router to catch undocumented routes; the blocking `contract` job in `.github/workflows/ci.yml` makes drift a build failure. |
| T-02-62 | Information disclosure | A documented response example carrying real case, party or recipient data into a public contract artifact | mitigate | Examples are authored from the seeded fixture vocabulary only; task 3 assertion 5 validates `error_code` values against the FRD catalogue, and the register review in task 2 is the point at which examples are read. Residual risk is a reviewer miss, accepted and owned by code review. |
| T-02-63 | Repudiation | A deviation from a binding spec existing only in code, so a later reader cannot tell intentional divergence from a defect | mitigate | `docs/SPEC-DEVIATIONS.md` records DEV-01…DEV-04 and EXT-01…EXT-07 with the spec text quoted and the corrected-contract location named; `docs/SCHEMA-NOTES.md` cross-references it; the three FRD `[ASSUMPTION]` markers are carried verbatim into `packages/config-schema/src/index.ts`, `acknowledgement.service.ts` and `search.service.ts`. |
</threat_model>
